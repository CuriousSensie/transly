# Transly

  This is a simple transcription and translation service using ML <br>
  Check the app: <a href="https://translyml.netlify.app/"> click here <a/>
  <br> <br>
  Transly has been implemented using: <br>
    React <br>
    TailwindCSS<br>
    Vite<br>
    Swal<br>
    FontAwesome<br>
    Firebase authentication<br>
    Xenova/Transformers to run the Machine Learning Models<br>
<br>
Further implementation:<br>
  Since I have setup the Login/signup part, I also want to store the text everytime the service is used so the user can revisit and reuse. <br>
  The Xenova/Transformer library is slow (not actually slow, but since it has a glitch where for me, I can only use the remote models, which means the user has to load the ML models from a remote server everytime. Which is slow. Whenever Xenova fixes this, I will implement the fix.
